# TapVRM — 敲一下，分身知道嗎？

輕敲 MacBook，機身裡的加速度感測器會即時把訊號傳給瀏覽器裡的 VRM 分身。分身被敲到會往後仰，也會跟著筆電傾斜。可以換成自己的 VRM。

由 ChatGPT 版的模擬示範（`bridge.py --replay`）改寫而來，改成接收真正的感測器資料。

## 使用

1. 點兩下 `dist/TapVRM.app`（或打開 `dist/TapVRM.dmg`，把 App 拖進「應用程式」）
2. macOS 跳出密碼視窗時輸入密碼。讀取加速度感測器需要系統權限
3. 瀏覽器會自動打開頁面，感測器狀態顯示「實機感測中」後就可以敲了
4. 要結束時按頁面上的「結束 TapVRM」，感測器程式會一起關閉

想看 log 的話，可以點兩下 `TapVRM.command`，用終端機視窗執行。關掉視窗就會結束。

### 換自己的 VRM
- 按「換成自己的 VRM」選檔，或直接把 `.vrm` 拖進視窗。VRM 0.x / 1.0 都支援
- 模型只在瀏覽器本機讀取，不會上傳。下次打開會自動載入上次用的角色（存在瀏覽器的 IndexedDB）
- 「換回內建角色」可以回到課堂機器人

### 頁面功能
- **即時波形**：機身的動態加速度（g）。虛線是觸發門檻，綠點是有回應的敲擊，灰點是低於門檻的敲擊
- **觸發門檻**：敲擊振幅 ≥ 門檻才會讓分身反應（預設 0.05 g，跟 spank 相同）
- **跟著筆電傾斜**：用重力方向算出左右/前後傾角，分身會跟著歪。「以目前姿勢為水平」可以重新校正
- **依敲擊方向歪頭**：敲擊有左右分量時，頭會往那一側晃
- **螢幕角度**：把螢幕闔到快關上時，分身會變得想睡（眼睛半閉）
- **會講話**：分身會依情況講話，頭上會出現對話泡泡，並用 macOS 中文語音（優先用美佳）唸出來，嘴巴同步動。可以分別關掉「會講話」和「唸出聲音」
- **模擬按鈕／回放**：沒有感測器時也能教學

### 分身會說什麼
| 情況 | 判斷方式 | 例句 |
|---|---|---|
| 重拍 | 振幅 ≥ 0.25 g | 哇靠！被重拍了！ |
| 中等 | 0.12–0.25 g | 嘿！有人敲我？ |
| 輕拍 | 門檻–0.12 g | 喔喔～被輕輕拍！ |
| 連打 | 2.5 秒內 3 次 | 連打？！別再拍了啦！ |
| 歪斜 | 傾斜 > 12° 持續 0.6 秒（> 30° 換更慌的台詞） | 啊～歪歪的快要站不穩了 |
| 回正 | 歪斜後回到 5° 以內 | 呼～終於站穩了 |
| 螢幕快闔上／打開 | 螢幕角度 < 40° ／ > 70° | 好暗喔…要睡了嗎？／早安！ |
| 打字 | 桌面持續小震動，明顯高於底噪 | 你在打字嗎？桌子一直在抖耶 |
| 太久沒人理 | 45 秒沒有敲擊 | 好無聊喔…敲我一下嘛 |

台詞和每種情況的冷卻秒數都寫在 `src/talk.js` 的 `LINES`、`COOLDOWN`，改完執行 `./build.sh` 重新打包即可。瀏覽器規定頁面要先被點過一下才能出聲，在那之前只會顯示泡泡。

在瀏覽器 console 也可以手動觸發：`tapvrm.react(0.3, '手動')`、`tapvrm.say('tilt')`。

## 硬體需求
Apple Silicon MacBook，晶片要 M2 以上（或部分 M1 Pro），跟 spank 相同。已在 M4 Max MacBook Pro（Mac16,6）上測試。

## 運作方式

```
TapVRM.app ──(一般使用者)── 127.0.0.1:8131 網頁 + SSE 串流 ──► 瀏覽器（three-vrm）
     │  unix socket（只有自己可讀寫）
     └──(root，經 macOS 密碼視窗授權)── tapvrm sensor：IOKit HID 加速度計 / 螢幕角度
```

- 同一個執行檔分成兩個角色。網頁服務以一般使用者身分執行。只有 `tapvrm sensor` 這個小程式拿 root 權限，它只讀感測器，並把 JSON 送回主程式
- 主程式結束或被強制關閉時，root 小程式會在 1 秒內自動退出
- 服務只綁定 127.0.0.1。啟動感測器和結束程式的 API 要帶自訂 header，其他網站無法跨站觸發
- 已經在執行時再點一次 App，只會重新打開頁面，不會再問一次密碼
- 感測器底層用 [taigrr/apple-silicon-accelerometer](https://github.com/taigrr/apple-silicon-accelerometer)（spank 也是用這個），敲擊偵測用它的 STA/LTA + CUSUM 偵測器，跟 spank 的振幅尺度一致

### 指令列選項
```sh
./tapvrm                         # 一般啟動（會跳密碼視窗）
./tapvrm --replay events.jsonl   # 不讀感測器，循環播放 spank 格式的事件
./tapvrm --no-sensor --no-open   # 只開網頁服務
./tapvrm --port 9000 --web web   # 換連接埠；直接讀 web/ 資料夾（開發用）
```
如果終端機裡先跑過 `sudo -v`，主程式會沿用 sudo 授權，不會跳視窗。

## 從原始碼建置
```sh
./build.sh        # → tapvrm、dist/TapVRM.app
./build.sh dmg    # 另外產生 dist/TapVRM.dmg
```
需要 Node.js（esbuild 打包前端）和 Go 1.26+。如果 `.toolchain/go` 存在，會優先用它（本機的系統 Go 是 1.17，不夠新）。

- `main.go`：感測器小程式 + 本機服務
- `src/viewer.js`：前端原始碼；`src/talk.js`：台詞和說話邏輯。`web/app.js` 是打包結果，用 three r185 + @pixiv/three-vrm 3.5.5
- `web/index.html`、`web/classmate.vrm`：頁面和內建角色

App 只有 ad-hoc 簽章，適合在這台 Mac 上使用。如果要給別台 Mac 使用，需要 Developer ID 簽章和公證，否則 Gatekeeper 會擋。

第三方授權見 `licenses/`。
